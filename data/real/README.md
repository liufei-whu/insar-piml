# Preprocessed real-event InSAR

This directory contains the compact 64x64 dual-track products used by the real-event
evaluation and figures: Jishishan (2023), Albania (2019), and Morocco (2023).

Each NPZ contains preprocessed ascending/descending LOS observations plus the physical
grid, masks, and pixel-wise LOS geometry required by `src/evaluate_real.py`.

These are derived/preprocessed research products, not original satellite scenes. This
repository does not claim ownership of upstream observations; users should consult the
relevant upstream provider terms before redistribution or reuse.
